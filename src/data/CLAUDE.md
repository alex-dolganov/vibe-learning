# src/data — данные курса

## course.js

Экспортирует `courseData` — массив глав.

### Структура

```js
courseData = [
  {
    id: Number,          // порядковый номер главы (1, 2, 3...)
    title: String,       // название главы
    lessons: [
      {
        id: String,      // "глава-урок", например "1-1", "3-2"
        title: String,   // название урока
        content: String, // markdown-строка с контентом урока
      }
    ]
  }
]
```

### Добавить новую главу

```js
{
  id: 6,
  title: "Название",
  lessons: [
    { id: "6-1", title: "Урок 1", content: `# Заголовок\n\nТекст...` },
  ]
}
```

### Добавить урок в существующую главу

Добавить объект в `lessons[]` нужной главы. ID: `"${chapterId}-${lessonIndex}"`.

### Формат content

Обычный Markdown. Поддерживается: h1–h3, bold, italic, ul/ol, blockquote, code (inline и block), table.
Пишется как template literal. Символы `` ` `` внутри экранировать как `\``.
